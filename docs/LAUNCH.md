# Launch Plan

## Positioning

**depattern is an AI-pattern linter for serious writing.**

It flags formulaic phrasing, flat rhythm, vague abstractions, repeated openers, and weak answer-first structure. Then it gives concrete edit suggestions and can rewrite drafts with a configured LLM provider.

Do not position it as an AI detector. It is a writing linter.
